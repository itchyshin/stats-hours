# Coverage — what a reader can run, chapter by chapter

This is a book, so its capability surface is coverage: for every chapter, is the Julia taught path
executed at build, is the R comparison box pre-rendered from a real run, and can a reader run the
chapter on a hosted machine without installing anything. `covered` means verified by the build or
by a measured run; `partial` means it exists but is unverified; `planned` means not yet.
