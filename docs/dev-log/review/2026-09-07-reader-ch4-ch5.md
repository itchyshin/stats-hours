# Reader pass — Class 4 and Class 5

**Reviewer stance:** a biology graduate student, one statistics course, no Julia, reading
`docs/site/book/wk4-overdispersion.html` and `docs/site/book/wk5-diagnostics.html` as served
(checked against `book/wk4-overdispersion.qmd` and `book/wk5-diagnostics.qmd`). Method: pulled the
rendered DOM (dialogue `<p>` tags, code-cell output, exercises, masthead) and read it the way a
reader meets it — not the source markdown. Every quote below is exact rendered text; every rewrite
keeps the inline numbers exactly as printed (marked "keep the inline number").

**Verdicts**

- **Class 4 (`wk4-overdispersion`): light pass.** The statistics teaching itself is clean and
  well-scaffolded. The defects are all vocabulary leaks — a GitHub issue number spoken in
  dialogue, the literal phrase "this page's seed," one line calling the software's own flaw a
  "bug report," and one unexpanded abbreviation in printed output. None of these break the
  statistical argument; all of them are a sentence-level rewrite.
- **Class 5 (`wk5-diagnostics`): real pass.** Two exercises point the reader at internal Quarto
  cell labels (`guard-silence`, `null-envelope`) that resolve to nothing a reader can see. One
  code cell prints a raw Julia stack trace with a package file path and line number
  (`~/.julia/packages/DRM/WUZrp/src/comparison.jl:70`). The word "guard" — an internal-code
  term — is used three times, including as an exercise title. One line calls the engine's own
  flaw "the bug." These need author attention before the page is reader-ready; the statistics
  content around them is otherwise the strongest diagnostic chapter in the pair.

## The ten worst passages (both pages, ranked)

1. **[Ch5, code cell `guard-order`, printed error]** The rendered page shows, verbatim:
   > `ArgumentError: lrtest: `full` must have more parameters than `reduced` (dof(full) = 2, dof(reduced) = 3; did you pass the arguments as (reduced, full)?)`
   > `Stacktrace:`
   > ` [1] lrtest(reduced::DrmFit{Poisson}, full::DrmFit{Poisson})`
   > `    @ DRM ~/.julia/packages/DRM/WUZrp/src/comparison.jl:70`
   > ` [2] top-level scope`
   > `    @ In[41]:1`

   This is an engine source file, a line number, and Julia/Jupyter REPL internals
   ("top-level scope", "In[41]:1") printed directly on the page — exactly what a reader must
   never meet. Itchy's own dialogue right after this ("It refused, it named the rule, and it
   named the fix, which is what an error message is for") only needs the first line. **Fix:**
   the `#| error: true` cell should print or be followed by only the `ArgumentError:` line; drop
   the `Stacktrace:` block and everything under it. No inline number to preserve — this is pure
   machinery, not content.

2. **[Ch5, Exercise 9, "Break the guard, and find the hole"]** Exact quote: *"Then, as
   `guard-silence` does, fit your reduced model (fewer terms) to one subset of your rows..."*
   `guard-silence` is the Quarto cell label from the source (`#| label: guard-silence`), rendered
   as `<code>guard-silence</code>` — it looks like a function name but resolves to nothing the
   reader can call or find. The sentence already describes the procedure in full right after
   naming it. **Rewrite:** *"Then fit your reduced model (fewer terms) to one subset of your
   rows and your full, nested model (one extra term) to a different subset of rows, compare the
   pair with `lrtest`, and paste the number it returns."* (Delete "as `guard-silence` does" —
   the instruction survives untouched without it.)

3. **[Ch5, Exercise 3, "Calibrate the envelope, with the null that applies"]** Exact quote: *"Then
   build the diagnostic's own null, the way `null-envelope` does..."* Same defect as #2: a
   Quarto cell label, not a reader-visible name. **Rewrite:** *"Then build the diagnostic's own
   null, the way this class did: simulate 2000 datasets from your fitted model with an explicit
   `rng`, refit the same formula to each invented world, recompute the quantile residuals, and
   run the same counter on each."*

4. **[Ch4, "Suspect the mean before you blame the family", Itchy]** Exact quote: *"Our engine
   cannot write it — DRM.jl 0.7.1 exports no `offset` (that is [DRM.jl issue #727]) — so I am
   teaching the free coefficient and showing you the pinned version in R, where it is one word."*
   A GitHub issue number, rendered as a live link, spoken in dialogue. `writing-conventions.md`
   is explicit: at most one issue number in the whole chapter, and only in a Julia-stuff bullet
   ("a known limitation, reported") — never in dialogue. The chapter already has the correct,
   permitted instance in the Julia-stuff summary bullet ("There is no `offset` in DRM.jl 0.7.1
   (issue #727)"), so this one is a second, disallowed copy. **Rewrite:** *"Our engine cannot
   write it — DRM.jl 0.7.1 has no `offset` yet — so I am teaching the free coefficient and
   showing you the pinned version in R, where it is one word."* (Move the citation, if wanted,
   to the Julia-stuff bullet only, where it already lives.)

5. **[Ch4, "It sags on the left and bulges in the middle" beat, printed output + Itchy]** Printed,
   verbatim: *"this page's seed: 49; a symmetric residual would give 27"*, and Itchy then says:
   *"the seed this page happens to draw gives `w_bb.neg_left`, near the top of that range, so
   quoting *that* number as the evidence would have overstated the shape by a third."* This is
   the literal phrase the conventions doc names as forbidden ("this page's seed"). **Rewrite the
   printed line:** `"the draw shown above gave: 49; a symmetric residual would give 27"` (keep
   the inline numbers). **Rewrite the dialogue:** *"the particular draw shown above gives 49,
   near the top of that range, so quoting that number as the evidence would have overstated the
   shape by a third."* (keep the inline number)

6. **[Ch4, "Can I see the assumption itself..." beat, Itchy]** Exact quote: *"The engine's note is
   not family-aware and should be; that is a bug report, not a lesson."* "Bug report" is
   software-development vocabulary, not a stats concept, and it reframes a teaching aside as an
   internal ticket. **Rewrite:** *"The engine's note is not family-aware — it should say so —
   but that is a flaw in the tool, not a lesson for you. Read the line, then decide whether it
   applies to your family."*

7. **[Ch5, "Never accept a null" beat / row-count guard, Itchy]** Exact quote: *"Then look at the
   p-value: exactly one, because the code takes the larger of the statistic and zero before
   referring it to a chi-squared, so an impossible statistic is reported as the most reassuring
   result the test can give. That p-value is not a warning; it is the shape of the bug."*
   Calling the engine's own clamping behaviour "the bug" mid-lesson is the same defect as #6.
   **Rewrite:** *"That p-value is not a warning; it is what a broken assumption looks like once
   the arithmetic can no longer tell you so."*

8. **[Ch5, Objectives, item 5]** Exact quote: *"...say what the engine's comparison guard
   refuses, what it merely warns about, and what it cannot check at all."* "Guard" is an
   internal-code term (a guard clause), never defined for the reader, and it recurs twice more
   below (#9, #10) — three unexplained uses of one piece of jargon in a single chapter.
   **Rewrite:** *"...say what comparisons the engine refuses outright, what it only warns you
   about, and what it cannot check at all."*

9. **[Ch5, "What the engine refuses, and what it does not", Itchy]** Exact quote: *"`anova` is the
   same function under drmTMB's spelling, so the guard is the same either way."* **Rewrite:**
   *"`anova` is the same function under drmTMB's spelling, so the refusal is the same either
   way."*

10. **[Ch5, Exercise 9 title]** Exact quote: *"**Break the guard, and find the hole.**"* Third use
    of "guard" as an exercise title — the single most visible instance, since it is the first
    thing a reader sees before the exercise body. **Rewrite:** *"**Trigger the refusal, and find
    the hole.**"*

**Honourable mentions, just outside the top ten** (both real, both smaller):

- **[Ch4, printed output, worm-arithmetic/beta-binomial block]** *"Binomial : RQR SD 1.2883
  (5.21 MC SE from 1)..."* and *"BetaBinomial : RQR SD 1.0722 (1.30 MC SE from 1)..."* (keep the
  inline numbers). "RQR" (randomised quantile residual) is never spelled out anywhere in the
  chapter — every other mention says "quantile residual" in full. **Rewrite:** drop the
  abbreviation and print *"Binomial : quantile-residual SD 1.2883 (5.21 MC SE from 1)..."*, matching
  the wording used everywhere else on the page.
- **[Both pages, masthead, rendered on every chapter]** *"Every draw from a random number
  generator is seeded in the cell that makes it."* ("Cell" is a Quarto/notebook term, not a
  reader concept.) **Rewrite:** *"Every draw from a random number generator is seeded where it
  is made."* This is site-wide template text, not chapter prose, so flagging once for both pages

## Class 5 (`wk5-diagnostics`) — full list

**Verdict: real pass.**

### Masthead (site-wide template)
- Same "seeded in the cell that makes it" defect as Class 4; not repeated here.

### Objectives, item 5 — prose (not dialogue, but reader-facing)
- *"...say what the engine's comparison guard refuses, what it merely warns about, and what it
  cannot check at all."* — worst-passages #8.

### "What the engine refuses, and what it does not" — Itchy
- Code cell `guard-order`, printed error with full Julia stack trace, file path and line number
  — worst-passages #1. This is the single worst passage on either page.
- *"`anova` is the same function under drmTMB's spelling, so the guard is the same either way."*
  — worst-passages #9.
- *"There are more refusals in there that you will not meet today — the engine throws if you
  compare two restricted-likelihood fits with different fixed effects, it throws on a pair of
  fits that used different marginal approximations, it throws on penalised fits, and it warns if
  the extra parameter you are testing is a variance component, because then the null sits on a
  boundary and the chi-squared reference is wrong."* — one 71-word sentence stacking five
  technical phrases ("restricted-likelihood fits," "marginal approximations," "penalised fits,"
  "variance component," "boundary," "chi-squared reference") with no pause and no gloss. Itchy
  does flag it as forward-reference ("you will not meet today"), which softens the stakes, but a
  reader still has to parse it. **Rewrite (split in two, keep every clause):** *"There are more
  refusals in there that you will not meet today. The engine throws if you compare two
  restricted-likelihood fits with different fixed effects, or two fits that used different
  approximations for the random effects, or a penalised fit. And it warns you if the extra
  parameter you are testing is a variance — because then the comparison sits on a boundary the
  usual reference distribution does not expect."*
- *"Then look at the p-value: exactly one, because the code takes the larger of the statistic and
  zero before referring it to a chi-squared, so an impossible statistic is reported as the most
  reassuring result the test can give. That p-value is not a warning; it is the shape of the
  bug."* — worst-passages #7.

### Exercises
- Exercise 3: *"the way `null-envelope` does"* — worst-passages #3.
- Exercise 9 title: *"Break the guard, and find the hole."* — worst-passages #10.
- Exercise 9 body: *"Then, as `guard-silence` does, fit your reduced model..."* — worst-passages
  #2.

### Everything else
- The three-residuals section, the worm-plot calibration section, and the simulation-check
  section (roughly two-thirds of the chapter) read cleanly: every term (response residual,
  Pearson residual, randomised quantile residual, worm plot, envelope, Monte Carlo SE) is given
  a one-line definition at first use, in dialogue, before the printed output that uses it. The
  "two nulls" and "four nulls" beats are dense but are dense about the actual statistics, not
  about machinery, and each one is walked through with a concrete number rather than asserted.
  No retired-claim drift found against the Summary or Exercises.

## Summary for the caller

- **Class 4: light pass** — 4 real defects (issue number in dialogue, "this page's seed" x2,
  "bug report," one unexpanded abbreviation), each a one-sentence fix, no structural problems.
- **Class 5: real pass** — 2 exercises reference unresolvable internal cell labels, 1 code cell
  prints a raw stack trace with an engine file path and line number, "guard" (internal-code
  vocabulary) used 3 times including as an exercise title, 1 "bug" framing, 1 overloaded 71-word
  sentence. The diagnostic content itself is the best-taught material in either chapter; the
  defects are all late-pass polish, not a design problem.
- Both pages share one lower-priority, site-wide masthead defect ("seeded in the cell that makes
  it" / "the book itself is not written") that is template text, not page-specific prose — worth
  a decision from whoever owns the shared header rather than a per-chapter fix.
