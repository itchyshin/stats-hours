# Reader pass — Class 3 and Class 10

Read as the intended reader: a biology graduate student with one statistics course and no
Julia, reading the rendered web page. Checked against `docs/writing-conventions.md`, section
"What a reader must never meet". Source: `book/wk3-glms.qmd` / `docs/site/book/wk3-glms.html`
and `book/wk10-relatedness.qmd` / `docs/site/book/wk10-relatedness.html`, rendered text
extracted with `html.parser` (script/style stripped) rather than read from source, so every
quote below is what actually reaches the reader.

## Verdicts

- **Class 3 (`wk3-glms`): light pass.** The chapter is a good model for the rest of the book —
  every statistical term it introduces (odds, odds ratio, log-odds, rate ratio, quantile
  residual, overdispersion, Monte Carlo SE) is defined in the same breath it is first used, and
  there is no engine-internals leak. Two real gaps (`delta-method`, `worm plot`) recur and should
  be fixed the way the chapter fixes everything else.
- **Class 10 (`wk10-relatedness`): real pass.** This is the hardest chapter in the book and most
  of its density is earned — the animal-model story genuinely needs REML vs ML, boundary tests,
  and a relatedness matrix. But three passages put raw engine internals (a Julia stacktrace with
  a package cache path and line number, two source-file names, one underscore-prefixed internal
  function name) directly in front of the reader, which is exactly what the convention forbids,
  and several statistical terms are used one or more classes before they are ever defined on the
  page.

## The ten worst passages (both pages, ranked)

1. **Ch10, "One term, and a matrix," code output (no speaker — engine output Momo and Itchy then
   read from).** Full Julia stacktrace:
   > `Stacktrace: [1] drm(f::DrmFormula, fam::Gaussian; data::DataFrame, K::Nothing, A::Matrix{Float64}, tree::Nothing, coords::Nothing, g_tol::Float64, algorithm::Symbol, method::Symbol, profile_ci::Bool, phylo_coupled::Bool, penalty::Nothing, sparse::Nothing, impute::Nothing, missing::Nothing) @ DRM ~/.julia/packages/DRM/WUZrp/src/gaussian_core.jl:672 [2] top-level scope @ In[10]:1`

   This is precisely "engine source files or line numbers" — a package-cache path, a versioned
   hash directory (`WUZrp`), a file and line (`gaussian_core.jl:672`), and a Jupyter cell counter
   (`In[10]:1`) that means nothing to a reader who has never opened a REPL. The convention that
   "errors stay in" covers the *message* — Itchy and Momo do real teaching with it a moment
   later. It does not require the stacktrace. **Rewrite:** drop the `Stacktrace:` block entirely;
   keep only the `ArgumentError:` line (itself flagged below) and Itchy's line "It says no, and
   read how it says no."

2. **Ch10, same code block, the `ArgumentError` text itself, quoted again by Momo a moment
   later.** Exact text:
   > "`ArgumentError: drm: method = :REML is not implemented for this model on the generic
   > univariate Gaussian route (random slopes, a random effect on sigma, a structured mean
   > marker — phylo/relmat/animal/spatial — without a matching sd() submodel, and meta_V() all
   > land here). REML IS available for: the fixed-effect Gaussian location–scale model; a single
   > Gaussian mean random intercept `(1 | g)`; every sd() LSS route (`sd(g)`, `sd_phylo` dense
   > and sparse, and the multi-component sd() router); the bivariate structured routes (q=2 and
   > q=4, both native and via drm_bridge); and Poisson `(1 | g)` and Poisson `phylo(1 |
   > species)`. Use method = :ML (the default) for this model.`"

   "generic univariate Gaussian route," "sd() submodel," "meta_V()," "sd_phylo," "the sd() LSS
   route," "drm_bridge" are all internal routing names inside the engine, not part of the
   taught vocabulary (`animal()`, `relmat()`, `phylo()`, `spatial()` are taught; these are not).
   Momo then reads a shortened version of the same text aloud, which repeats the leak. **Keep the
   number and the shape of the refusal** — Itchy's point that "a package that publishes its own
   boundary is worth two that quietly approximate over it" is good teaching — **but the message
   itself needs paraphrasing**, e.g.: *"REML is not implemented for a model with a structured
   random effect like `animal(1 | id)`. It is available for a plain random intercept, for the
   location–scale model, and for a couple of named special cases — not for this one. Use `method
   = :ML` (the default) instead."* That keeps every fact Itchy and Momo go on to use (there is a
   list of exceptions, the engine names its own boundary) without the route jargon.

3. **Ch10, Summary → Julia stuff bullet on `heritability`/`repeatability`.** Exact text:
   > "The returned object carries `estimate`, `bias`, `corrected`, `se` and `ci` — and `ci` is
   > `corrected` ± z·se, not `estimate` ± z·se (`bias_correct.jl`), then clamped into [0, 1]
   > (`heritability.jl`)."

   `bias_correct.jl` and `heritability.jl` are literal engine source-file names, cited as if they
   were a reference a reader could look something up in — the exact pattern the review brief
   warns about. Nothing is lost by dropping the parentheses. **Rewrite:** *"The returned object
   carries `estimate`, `bias`, `corrected`, `se` and `ci` — and `ci` is `corrected` ± z·se, not
   `estimate` ± z·se, then clamped into [0, 1]."*

4. **Ch10, Summary → Stats stuff, last bullet (on the interval and the bias correction).** Exact
   text:
   > "And a bound of exactly 0 or exactly 1 is not a computed bound: it is `_clamp01` acting on a
   > value that fell outside, which is a thing to declare rather than to enjoy."

   `_clamp01` is a raw internal function name (the leading underscore marks it as unexported/
   private even in Julia's own convention) sitting in a sentence a reader is meant to take away
   as the chapter's lesson. **Rewrite:** *"And a bound of exactly 0 or exactly 1 is not a computed
   bound: it is the engine capping a value that fell outside [0, 1], which is a thing to declare
   rather than to enjoy."*

5. **Ch10, code comment inside "One term, and a matrix" (visible in the transcript) and the
   matching Julia-stuff bullet — "eigenbasis" used with no definition.** Exact text (comment):
   > "so `A` and the residual share an eigenbasis: in the coordinates `U'y` the covariance is
   > DIAGONAL"

   and (Julia stuff): "`eigen(Symmetric(A))`: with one record per individual, `A` and the
   residual covariance share an eigenbasis, so in the rotated coordinates `U'y` the whole model
   is diagonal." A reader with one statistics course has not met eigenbases. The consequence
   ("the covariance is diagonal, so one refit costs O(n) instead of a dense solve") is exactly
   the teachable content; the word "eigenbasis" is not needed to say it. **Rewrite (comment):**
   *"so `A` and the residual noise can be rotated onto the same coordinate axes at once — in the
   rotated coordinates `U'y` the covariance is DIAGONAL."* Apply the same swap in the Julia-stuff
   bullet.

6. **Ch3, "The model that is the right shape," code output + Ch3/Ch10 Julia stuff, and Ch10
   dialogue — "delta-method" used with no one-line definition anywhere on either page.** Exact
   text (Ch3, printed output line, keep the inline number):
   > "at 3.5 g, delta-method SE on that probability: 0.0134"

   and (Ch3 Julia stuff): "Add `se = true` for a delta-method standard error." (Ch10 repeats it
   at least four times, e.g. "delta-method SE : 0.0452", "the printed one is the delta-method
   default.") The reader is never told what a delta-method standard error *is* — only that it
   exists and has a name. **Rewrite (first use, Ch3):** *"at 3.5 g, standard error on that
   probability: 0.0134 (found by carrying the model's uncertainty on the log-odds scale through
   the squashing function onto the probability scale — the "delta method")"* — one clause, said
   once, then the bare term can carry the rest of both chapters.

7. **Ch3 (Figure 3 caption) and Ch10 (Figure 3 caption + dialogue) — "worm plot" named
   repeatedly, never told why it looks the way it does or what a reader should read off it
   beyond "close to the line is good."** Exact text (Ch3, Julia stuff, the closest thing to a
   definition the pages give): "`fig_diagnostic(resid)` from `tools/figures.jl`: the worm plot,
   which is exactly the right picture for quantile residuals because they are normal when the
   model is right." That sentence says the plot exists and what it is *for*, not what it *shows*
   (sorted residuals against the normal quantiles they would have if the model were right — the
   thing that makes it read as a worm when the model is wrong). **Rewrite:** add one clause on
   first mention (Ch3, Figure 3 caption or the sentence just before it): *"a worm plot lines the
   residuals up from smallest to largest and compares them, one by one, to where a perfect
   standard-normal sample would sit — a flat scatter close to zero means nothing is left to
   find; a curve or tilt means the model's shape is wrong somewhere specific."*

8. **Ch10, Summary → Stats stuff, boundary-test bullet.** Exact text:
   > "the likelihood-ratio statistic is 3.84 on 1 df, whose naive p is 0.0501 and whose
   > boundary-corrected p, under the 50:50 χ̄² mixture of Self & Liang (1987) and Stram & Lee
   > (1994), is 0.025."

   One sentence carries an unexplained "50:50 χ̄² mixture" notation on top of everything else in
   the bullet; a reader who followed the dialogue (which does explain the mixture in plainer
   words a few paragraphs earlier: "a 50:50 mixture of a point mass at zero and a chi-squared on
   1 df") hits the compressed notation-only version here with nothing to connect it back.
   **Keep every number.** **Rewrite:** *"the likelihood-ratio statistic is 3.84 on 1 degree of
   freedom. Read against an ordinary chi-squared table that gives p = 0.0501; read against the
   boundary correction from three sentences ago (half the usual p-value, because half the time
   the true difference is exactly zero) it gives p = 0.025."*

9. **Both pages, page header, "Engines" line.** Exact text (identical on both pages):
   > "Engines DRM.jl 0.7.1 at 4d9248f88 (Julia 1.10.0) · drmTMB 0.7.0 (R 4.6.0)"

   `4d9248f88` is a git commit hash — pure build machinery, meaningless to the reader, and not
   something either chapter's prose ever refers back to. This is template chrome rather than a
   chapter defect (it is presumably identical across every chapter in the book), so it is ranked
   here rather than dropped, but it is a genuine instance of "no engine source files or line
   numbers" reaching the page. **Rewrite (drop the hash, keep the version):** *"Engines DRM.jl
   0.7.1 (Julia 1.10.0) · drmTMB 0.7.0 (R 4.6.0)."* If the hash is load-bearing for the book's own
   reproducibility claims, it belongs in a colophon or the repository's README, not the reading
   surface of every chapter.

10. **Ch10, Summary → Julia stuff, `method = :profile` bullet.** Exact text:
    > "`method = :profile` gives a true profile-likelihood interval that re-maximises over the
    > nuisance parameters, and on a fit with many structured levels it is minutes rather than
    > seconds."

    "Profile-likelihood interval" and "nuisance parameters" are both used as if already familiar;
    neither is on the hunt list's exemption (they are not expanded anywhere on the page, and
    "nuisance parameter" is genuinely obscure to a one-course reader — it means "a parameter the
    model has to estimate along the way that nobody asked about"). **Rewrite:** *"`method =
    :profile` gives a true profile-likelihood interval — instead of using one quick formula, it
    re-fits the whole model at a grid of trial values and finds exactly where the fit gets
    significantly worse. On a fit with many structured levels that re-fitting is minutes rather
    than seconds."*

## Full findings by page

### Class 3 — `book/wk3-glms.qmd` / `docs/site/book/wk3-glms.html` — light pass

What the chapter already does right, for calibration: "odds," "log-odds," "odds ratio," "rate
ratio," "overdispersion," "quantile residual," and "Monte Carlo standard error" are all defined
in the same beat they are introduced (e.g. Toto: "Odds are the chance it happens divided by the
chance it does not," immediately after Itchy uses the word). "AIC" and "REML" are used but
carried over from Class 2/Class 8 rather than redefined, which is consistent with the book's own
convention of defining a term once across the whole book, not once per chapter — not flagged.

- **Section "The model that is the right shape," speaker Itchy/code output** — "at 3.5 g,
  delta-method SE on that probability: 0.0134" and the summary bullet using the same phrase with
  no expansion anywhere on the page. See worst-passage #6 above; **keep the inline number
  (0.0134)**.
- **Section "Is it any good?," Figure 3 caption + Julia stuff bullet** — "Worm plot of the
  two-predictor logistic fit's randomised quantile residuals" and "`fig_diagnostic(resid)` from
  `tools/figures.jl`: the worm plot" — named twice, never told what makes it a worm plot. See
  worst-passage #7.
- **Page header, "Engines" line** — shares the commit-hash issue with Class 10; see worst-passage
  #9. Low priority since it is template chrome, not chapter prose.
- **Not flagged, for the record:** the "Provenance" and "Caveat" boxes at the top of the page
  ("Every code block and printed result below was actually run, by Quarto executing this
  document end to end…") name Quarto and Rscript by name, but the writing convention explicitly
  sanctions exactly this transparency statement (see `docs/writing-conventions.md`, "Never invent
  output": "the R box, pre-rendered once from a real `Rscript` run and labelled with its date and
  versions"). This is a deliberate, sanctioned exception, not a leak, and the rule against "no
  Quarto cell options" is about `#| echo:`-style directives (confirmed absent from the rendered
  page — the `.qmd` source has them, but Quarto strips them at render), not about naming the tool
  in a provenance statement.

### Class 10 — `book/wk10-relatedness.qmd` / `docs/site/book/wk10-relatedness.html` — real pass

- **Section "One term, and a matrix," code output** — the full stacktrace with package-cache path
  and line number (`~/.julia/packages/DRM/WUZrp/src/gaussian_core.jl:672`) and Jupyter cell
  counter (`In[10]:1`). Worst-passage #1. Drop the `Stacktrace:` block; the `ArgumentError:` text
  above it (once paraphrased per #2) and Itchy/Momo's reading of it already carry all the
  teaching content.
- **Same code output, and Momo's line reading it aloud** — internal route names "generic
  univariate Gaussian route," "sd() submodel," "meta_V()," "sd_phylo," "drm_bridge." Worst-passage
  #2.
- **Summary → Julia stuff, `heritability`/`repeatability` bullet** — `bias_correct.jl` and
  `heritability.jl` cited by filename. Worst-passage #3.
- **Summary → Stats stuff, bias-correction bullet** — `_clamp01`. Worst-passage #4.
- **Code comment ("One term, and a matrix" cell) and Julia-stuff bullet** — "eigenbasis" used
  twice, undefined. Worst-passage #5.
- **Throughout, especially "One term, and a matrix" onward** — "delta-method SE" / "delta interval"
  used repeatedly (e.g. "delta-method SE : 0.0452", "delta-method default"), never defined on
  this page or Class 3. Worst-passage #6 covers the fix once, at first use in Class 3; Class 10
  can then use the bare term.
- **Figure 3 caption and surrounding dialogue** — "worm plot" used again with the same gap as
  Class 3. Worst-passage #7.
- **Summary → Stats stuff, boundary-test bullet** — the compressed "50:50 χ̄² mixture" notation.
  Worst-passage #8. Keep the numbers (3.84, 1 df, 0.0501, 0.025).
- **Page header** — same commit-hash issue as Class 3. Worst-passage #9.
- **Summary → Julia stuff, `method = :profile` bullet** — "profile-likelihood interval" and
  "nuisance parameters" unexplained. Worst-passage #10.
- **Section "What else do full sibs share," Itchy** — "A right-skewed positive response is what a
  Gamma family is for; the engine ships one, and no class in this book teaches it, which is a gap
  in the book rather than in the engine." This stays in Itchy's voice as the in-story teacher
  talking about "this book"/"this class," which the established narrative frame already permits
  (Itchy routinely refers to "Class 6," "Week 4," etc.). Not flagged as an authors-talking-to-
  each-other violation, but noted because it sits close to the line — if a future pass tightens
  this rule further, this is the sentence to look at first.
- **Section "Which of those two numbers should you believe?," Itchy, self-correction** —
  "One more thing before we go, because I said something too quickly earlier. The profile
  interval and the delta interval are not the same interval, and it is not clamping…" This reads
  like the kind of "retired claim" the convention warns about, but checked against the page: it
  correctly refers back to something Itchy *did* say on this same page (the clamped CI at "that
  lower bound BEFORE the engine clamps it into [0, 1]," a few screens earlier), so the reader has
  in fact seen the earlier claim. Not flagged as a defect — it is honest, on-page
  self-correction, not an invented retraction — but pending fix of the "delta-method"
  gap (#6), this passage will read more clearly once "delta interval" has a referent.
- **Not flagged, for the record:** "profile" is used as `method = :profile` and Kruuk's REML
  quote is left as a direct citation ("restricted maximum-likelihood animal models") rather than
  jargon dumped without attribution — both are handled the way the convention wants (one issue
  number equivalent, cited by source). The `↔︎ TRANSLATE` box's R code comment using
  `drmTMB:::drm_pedigree_additive_relationship(ped)` is an internal (triple-colon, unexported) R
  function name inside the sanctioned pre-rendered R box; lower priority than the Julia
  stacktrace since it is inside code (the established "code as REPL transcript" convention) and
  not inside a Summary bullet or dialogue line, but worth a look if the fixer has time — a
  reader who does not know R will not know `:::` marks an internal function, and it is not needed
  to make the translation box's point (that Julia leaves matrix-building to the user and R does
  not).
